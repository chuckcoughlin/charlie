## charlie
"Charlie" is a Booster K1 robot manufactured by Booster Robotics.


 The [Booster Manual](https://www.manualslib.com/manual/4118138/Booster-K1.html#manual) contains product specifics.

 Custom operations are described in a series of guides. See [Administration](http://github.com/chuckcoughlin/charlie/tree/master/docs/user-guide.md) for a description of network settings and other configuration tasks. These are accomplished though a direct wired connection to the robot.

 A second guide, [Direct Control](http://github.com/chuckcoughlin/charlie/tree/master/docs/user-guide.md) describes actions that are available through the game console. This remote control connects over Bluetooth to directly command gait parameters, adjust speeds, or test joint safety overrides manually. A similar guide, [Android Application](http://github.com/chuckcoughlin/charlie/tree/master/docs/user-guide.md), describes a tablet application that communicates through wi-fi. It handles diagnostic monitoring, and launching custom macro commands from the integrated motion library.

 The [Dancing](http://github.com/chuckcoughlin/charlie/tree/master/docs/user-guide.md) guide describes options available through the robot's "dance" interface. These are autonomous, repetitive motions executable in a special operations mode.

 [Jetson](http://github.com/chuckcoughlin/charlie/tree/master/docs/user-guide.md) is the custom programming SDK in Python using the embedded NVIDIA Jetson Orin NX module. It manages high-speed edge processes, stereo depth visual data, microphone arrays, and real-time inference loop routines completely detached from external hardware.

 [Training](http://github.com/chuckcoughlin/charlie/tree/master/docs/user-guide.md) describes the off-line training environment.

 [Simulation](http://github.com/chuckcoughlin/charlie/tree/master/docs/user-guide.md) describes usage of Webots, Mujoco, or Isaac Sim to guarantee proper walking dynamics before live mechanical engagement.
